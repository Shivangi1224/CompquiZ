# CompquiZ 💻🧠

A fun and interactive Flutter quiz app that tests your Computer Science knowledge!

## 📱 About the App

**CompquiZ** is a quiz application built with Flutter that challenges users with multiple-choice questions which contains questions related to Computer Science topics such as:

- Networking (TCP/UDP, HTTP)
- Data Structures
- Object-Oriented Programming
- Time Complexity
- Operating Systems
- And more!

The app provides explanations for correct answers, a progress bar, and a final score screen.

## ✨ Features

- Start screen with an engaging illustration
- Multiple-choice questions with immediate visual feedback (green/red)
- Explanation after each answer
- Progress bar to track quiz completion
- Result screen with score and different illustrations based on performance
- "Play Again" option to restart the quiz
- Custom fonts (Poppins + Inter)

## 🎨 Color Palette

- Soft Lavender (`#C8BCF1`)
- Khaki / Lime (`#E5F66D`)
- Lavender accent

## 🛠️ Prerequisites

Before running the project, make sure you have:

1. [Flutter SDK](https://docs.flutter.dev/get-started/install) installed
2. A code editor (VS Code / Android Studio)
3. An emulator or a real device (Android / iOS)

To check if Flutter is properly installed:

```bash
flutter doctor
```

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/Shivangi1224/CompquiZ.git
```
2. Navigate to the project folder:
```bash
cd CompquiZ
```
3. Get the dependencies:
```bash
flutter pub get
```
4. Run the app:
```bash
flutter run
```
